# The Home Rescue Book — Sales Page

## Upload to GitHub

Upload `index.html` and the entire `assets` folder.

The main file is already configured to use the supplied creative images.

## IMPORTANT — checkout link

Open `index.html` and find:

`const CHECKOUT_URL = "#";`

Replace `#` with your real checkout/payment URL.

The same checkout link is used by:
- Hero CTA
- Final CTA
- Mobile sticky CTA

## Testimonials

The page intentionally contains clearly marked testimonial placeholders. Replace them only with real customer reviews.

## GitHub Pages

After uploading:
Settings → Pages → Deploy from branch → select your main branch and `/root` → Save.
